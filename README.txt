PENNYWISE — EXPENSE & BUDGET TRACKER

OPEN IN VISUAL STUDIO CODE
1. Extract PennyWise_Normal.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Select the PennyWise_Normal folder.
5. Open index.html and run it with the Live Server extension (right-click > Open with Live Server), or double-click index.html to open it in a browser.

FEATURES
- Create account and sign in (demo authentication stored in this browser)
- Dashboard with income, expenses, balance and budget totals
- Add, edit and delete transactions
- Search and filter transactions
- Create and remove monthly budgets
- Income/expense bar chart and spending category chart
- Currency displayed in South African rand (ZAR)
- Responsive layout for desktop and mobile

IMPORTANT
This is a front-end portfolio/demo project. Data is stored in browser localStorage on the same browser/device. It does not use a remote database or production-grade authentication. Chart.js is loaded from a CDN, so an internet connection is needed for charts.
